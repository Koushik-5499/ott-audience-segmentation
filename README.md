# Containerized Audience Segmentation & Personalization Service

An end-to-end, deployable machine-learning service that understands OTT viewer behavior, groups users into meaningful behavioral segments, and exposes personalized recommendations through a containerized API.

## Architecture
The system is built as a three-tier Docker Compose application:
1. **Trainer**: Cleans synthetic data, engineers features, executes a strict K-Sweep, and securely persists the optimal `KMeans` Pipeline.
2. **API (FastAPI)**: Serves a robust `/recommend` endpoint, securely loading the persisted model and validating payloads with Pydantic.
3. **Evaluator**: Waits for API readiness and executes 25 edge-case and correctness tests, dumping results to `metrics.json`.

## Quickstart

Run the entire pipeline (Training -> API -> Evaluation) natively via Docker Compose:

```bash
# Tear down any old volumes
docker compose down -v

# Build and start all services
docker compose up --build
```

You can view the final metrics generated by the evaluator at:
```bash
cat ./output/metrics.json
```

To test the API manually while it is running:
```bash
curl -X POST http://localhost:8000/recommend \
  -H "Content-Type: application/json" \
  -d '{"user_id":"USR-TEST", "watch_time_hours":35.0, "top_genres":["Action", "Sci-Fi"], "avg_session_mins": 45.0}'
```
